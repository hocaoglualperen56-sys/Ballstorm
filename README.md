# BALLSTORM ✦

Neon temalı, mobil ve masaüstü tarayıcılarda oynanabilen bir brick-breaker prototipi.

## Nasıl oynanır?
- Oyun alanında topu göndermek istediğin yönün tersine doğru dokunup sürükle.
- Parmağını/fareyi bırakınca toplar fırlatılır.
- Numaralı blokları kır, jetonları topla ve seviyeleri geç.
- **Top Görünümleri** menüsünden jetonlarla yeni renkler aç.
- Puanın, jetonların ve açtığın görünümler aynı cihazın tarayıcısında saklanır.

## Dosyalar
- `index.html`: Oyunun tamamı (HTML, CSS ve JavaScript tek dosyada).

## Tarayıcıda yayınlama (GitHub Pages)
1. Depoda **Settings → Pages** sayfasını aç.
2. **Build and deployment** bölümünde kaynağı **Deploy from a branch** seç.
3. Branch olarak **main**, klasör olarak **/(root)** seçip **Save**'e bas.
4. Yayınlandıktan sonra GitHub Pages sayfasında gösterilen adresi aç.

Bu sürüm ilk oynanabilir prototiptir; ses efektleri ve daha fazla oyun mekaniği sonraki güncellemelerde eklenebilir.
